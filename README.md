# Catálogo Nexo

Proyecto estático de la vista **Productos** para la materia de Aplicaciones Móviles.

## Cómo abrirlo

No requiere instalación, servidor, Internet, Bootstrap ni framework. Abre el archivo `index.html` en un navegador.

## Estructura

- `index.html`: estructura de la pantalla.
- `css/styles.css`: estilos para escritorio y móvil.
- `js/products.js`: productos de demostración locales.
- `js/app.js`: búsqueda, filtro, paginación y vista de detalle.
- `assets/img`: imágenes locales de los productos.

## Funciones

- Búsqueda por nombre.
- Filtro por categoría.
- Paginación.
- Vista de detalle al seleccionar un producto.
